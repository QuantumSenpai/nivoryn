# API and compatibility decisions

Documentation was checked with Context7 on 24 November 2026. Library IDs below were returned by `resolve-library-id`, then queried; they were not assumed. Context7 snippets are discovery aids: versioned upstream Java source and actual installed AAR execution determine the runtime contract.

| Area | Resolved Context7 ID | Decision / upstream reference |
|---|---|---|
| ExecuTorch | `/pytorch/executorch`, queried `/pytorch/executorch/v1.2.0` | Keep tested dependency-locked 1.2.0 and its Arm64 native operators. [`LlmModule.java`](https://github.com/pytorch/executorch/blob/v1.2.0/extension/android/executorch_android/src/main/java/org/pytorch/executorch/extension/llm/LlmModule.java) is authoritative: positional `generate(prompt, seqLen, callback, echo)`, return code, `stop`, `resetContext`, `resetNative`. `seqLen` bounds total sequence, not a claimed output-only token count. Some Context7 convenience examples use different parameter names/callback shapes; they were not copied into the app. |
| Model/export/tokenizer | Same ExecuTorch ID | [Versioned Llama README](https://github.com/pytorch/executorch/blob/v1.2.0/examples/models/llama/README.md) links the published SpinQuant conversion. Exact revision, hashes, INT4/INT8 recipe, tokenizer content, operators, CPU ABI, licence and export limitations are recorded in MODEL_SETUP.md and trusted-model.json. |
| Compose state/navigation | `/websites/developer_android_develop_ui_compose` | [State saving](https://developer.android.com/develop/ui/compose/state-saving): save bounded input/navigation/scroll state; reload full saved assessments from encrypted history. Expensive work stays in services/coroutines. |
| Compose motion | `/websites/developer_android_develop_ui_compose_animation` was resolved; main Compose ID queried | [Animation APIs](https://developer.android.com/develop/ui/compose/animation/composables-modifiers): short state-driven selection/disclosure/transitions; no per-frame parsing/model initialization. Reference observations and chosen native timing are in NATIVE_MOTION_REFERENCE.md. |
| Bundled OCR | `/websites/developers_google_ml-kit` | [Android text recognition](https://developers.google.com/ml-kit/vision/text-recognition/v2/android): bundled Latin/Devanagari coordinates, `InputImage.fromBitmap`, recognizer completion/close. Actual offline cold-process extraction tested; no first-use resource download assumption. ML Kit SDK terms apply separately. |
| QR | `/zxing/zxing` | [MultiFormatReader](https://zxing.github.io/zxing/apidocs/com/google/zxing/MultiFormatReader.html): bounded image pixels → luminance/binary bitmap → local decode; missing payload remains missing. Never follow QR URLs. |
| Platform storage/security/import | `/websites/developer_android` | [Keystore](https://developer.android.com/privacy-and-security/keystore), [AtomicFile](https://developer.android.com/reference/android/util/AtomicFile), [ContentResolver](https://developer.android.com/reference/android/content/ContentResolver): private AES-GCM keys; synchronized atomic writes; provider streams closed; byte limits checked on actual reads. Restrict inspection to `content:` even though the platform API also accepts `file:`. MediaStore-owned pending files are test fixtures only. |
| Camera capture | `/websites/developer_android` | [TakePicture](https://developer.android.com/reference/androidx/activity/result/contract/ActivityResultContracts.TakePicture) and [FileProvider](https://developer.android.com/reference/androidx/core/content/FileProvider): narrow cache URI, explicit read/write grants and ClipData, contextual permission and import fallback. Android 17 requires explicit grants; real delegated camera and provider decoding were exercised. |
| Model download | `/websites/developer_android` | [DownloadManager](https://developer.android.com/reference/android/app/DownloadManager): OS-managed retry/resume and actual byte counters, persisted request IDs, explicit cancel/remove. Manual pause is not exposed. Verification and native inference follow completion. |
| Network observation | `/websites/developer_android` | [TrafficStats](https://developer.android.com/reference/android/net/TrafficStats) totals are aggregate and may be unsupported. [specialUse foreground service](https://developer.android.com/develop/background-work/services/fgs/service-types#special-use) with ongoing notification; no VpnService or packet-forwarding claim. |

The importer service has a cooperative 30-second deadline and checks cancellation before/after bounded processing. Neither Kotlin timeout nor native stop guarantees forced interruption of an unresponsive provider/platform parser. No library ID/API success is presented as hardware validation. Runtime evidence, pinned versions and remaining warnings are in PS3_VALIDATION.md and its report directory.
