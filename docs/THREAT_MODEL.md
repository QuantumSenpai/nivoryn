# Local engine threat model

Protected assets: imported private content, local cases, model integrity and the user's ability to distinguish observed evidence from heuristic or generated claims. The OS, app-signing identity and bundled code/catalogue are trusted. Imported text, QR payloads, providers, archives, captures and model files are untrusted. A compromised OS, root, malicious keyboard and screen observation remain outside the app's protection.

| Boundary | Protection | Validation / residual risk |
|---|---|---|
| URLs | Offline URI/IDN parsing; never requests, follows redirects or opens destinations | Host parser tests; redirects, current ownership and threat-feed reputation unavailable; no SSRF fetch surface |
| Prompt injection | Raw input/quotes/URL data excluded; only build-authored fact catalogue and approved action IDs; unknown titles replaced by a safe generic fact | Unit hostile-title/injection tests and real Llama injection/cancellation smoke pass; generated text never executes or creates intents; broad adversarial evaluation remains pending |
| Provider imports | Picker URI, bounded reads, fixed app-private temporary paths, cleanup in finally, no broad storage permission | Existing extraction boundary tests; malicious providers may stall reads; no guarantee of forcibly interrupting platform native work |
| Image/PDF | 20 MiB, dimensions/pixels bounded, downsampling, at most 20 PDF pages with only page 1 extracted; EXIF transforms; cooperative 30-second deadline and explicit cancel | Actual rotated JPEG, Hindi OCR, PDF/QR mismatch, blank and corrupt/excess-page tests pass in airplane-mode emulator; native isolation/fuzzing remains; crash temps may survive |
| PCAP | 20 MB, 100000 records, snap length bound, checked offsets and lengths; ignores unsupported traffic | Host parser and actual Android content-URI replay tests with synthetic fixtures; content may spoof IPs; port-count thresholds are not trained intrusion detection |
| APK | 20 MB, at most 10000 ZIP entries, 32 MB per entry and 200 MB declared expansion; rejects traversal; no extraction/execution/install | Platform archive parser still sees untrusted input; native/parser timeout isolation and full corpus testing remain |
| Model supply chain | Reviewed build-pinned catalogue, exact size/hash checks, fixed names, staged pair then atomic pointer; no sidecar trust | Pinned upstream-linked published conversion verified by Android generation/import; official Meta source also downloaded. Local exporter not reproduced. Release owner signing still needed; no remote app updater |
| Local history | Android Keystore AES-256-GCM, random nonce, atomic encrypted file in noBackupFilesDir; bounded size/count and retention | Tamper tests; drafts/saved task state are not encrypted history. No forensic-erasure claim. History stores text, QR and assessment snapshots; original input files are not retained |
| Android components | Launcher/plain-text share activity exported intentionally; app consumes text as data; backups/cleartext/network permission disabled | Merged manifest test; exported sharing and URI/provider abuse need broader device tests |
| Services/logging | No inference server, no app network permission, no TLS CA/interception; app does not log input or credentials | Dependencies can emit system warnings; native runtime logging with real prompts requires review before production |

Cancellation prevents UI delivery after cancellation; it cannot promise immediate termination of blocking native/provider calls. Model generation uses upstream stop, never frees native state during generation and permits one job. Real overlap/cancellation/next-request tests pass. Emulator memory samples exist in the runtime report; physical low-memory/storage and crash recovery still need target validation.

PCAP/APK inspection now shares a content-URI-only service, bounded actual reads, cooperative 30-second deadline, closed streams and fixed temporary APK cleanup. The same service is called by the UI and Android replay test. Invalid URI schemes, unknown-size oversized streams and malformed captures fail without a safety conclusion.

## Continuation protections

Encrypted history now includes bounded exact result snapshots via an explicit JSON schema, preserving original explanation mode on reopen. Legacy text-only records still load. Export uses an explicit SAF destination and warns that its JSON contains private text/evidence; the chosen provider controls that copy. Snapshot count/byte limits are enforced before an atomic encrypted write.

Model resources are staged by a digest-derived directory ID. Only complete pinned pairs activate through an AtomicFile pointer. Previous versions remain until deliberate deletion, and rollback verifies the still-trusted catalogue/digests. Interrupted local imports recheck the reselected prefix, enforce exact trusted size and final hash. Management and inference share a mutex; native resources are not freed during generation.

Signed indicator payloads are bounded and verified with separately build-pinned RSA publisher keys. Embedded/untrusted keys cannot confer trust. Version downgrade is refused except explicit verified rollback; stale/future packs cannot produce matches. No real publisher key/feed is bundled. Imported data never becomes an automatic fetch or executable remediation.

The 91 KB statistical model is an app asset trained only from the attributed public UCI corpus. Features are bounded and Kotlin/Python parity checked. It emits a cautious spam-like signal; it is not Llama or a fraud/Hindi classifier. Raw training messages are not bundled. Prompt facts come only from a controlled catalogue: interpolated evidence explanations, destination data and unknown titles never enter native prompts/logs. Hindi/Hinglish rule findings map to authored English advisory facts.

The separate Linux observer reads bounded same-UID /proc snapshots, never executes a submitted program and never reads environment/command-line secrets. It is not Android cross-app observation. RWX/temp-path/socket signals have benign explanations and are not malware proof.

Generated summaries now use a bounded JSON contract and per-sentence cited-evidence vocabulary checks, ASCII-only output, instruction/contact-detail/unsupported-certainty rejection and approved remediation IDs. This is a guardrail, not semantic entailment proof. Real-model adversarial evaluation remains required. Request identities prevent old analysis completion from navigating over a newer request; analysis/result share a stable transition key. Stop/unload operations synchronise native resource access. APK manifest metadata is capped at 2 MB; displayed permission/certificate/version lists and retained inspection state are bounded.

Final review adds generation-specific stop tokens (a cached module identity alone was insufficient), full JSON consumption/overflow refusal, conservative inverse-exposure rejection, hash-loop/pre-commit cancellation, bounded shared preview decoding and explicit preview timeout states. A cancellation arriving after an atomic resource commit cannot undo it; UI wording makes this race explicit. Unsupported audio no longer invokes an automatic platform player. APK metadata strips control/bidi formatting. Saved IDs survive resave, asynchronous history resolves after recreation, QR-only PDFs keep decoded content/source without inventing OCR, and interrupted export is disclosed. Analysis/history share bounded evidence/destination limits; capped evidence is announced.

When exactly one known finding supplies the context, the validator can attach that source reference to generated sentences before applying the same content checks. The result explicitly labels local binding rather than claiming that the model generated those references. Multiple findings require explicit valid references. This does not prove semantic entailment; broad adversarial evaluation remains pending. Raw generated synthetic test outputs and binding outcomes are retained for review.
