## Verification and provenance

Debug + unsigned release builds, host tests and lint are rerun after the final fixes. The expanded host suite has 86 cases; the actual Android suite has 18, including Llama generation, warm cancellation, imported OCR/PDF/QR, Keystore, history recreation/resave and static APK inspection. Exact final counts/warnings are recorded in PS3_VALIDATION.md and the runtime report. Two Python observer tests pass. Physical phone acceptance remains deferred; emulator results are explicitly separated from phone evidence.

The UCI corpus stays on ORBIT with original readme/provenance. Classifier evaluation: 4128 training / 1031 held-out rows after duplicate grouping; TP 113, FP 0, TN 903, FN 15. This does not establish scam or multilingual accuracy. Rules-only spam-proxy metrics are diagnostic and should be regenerated when rules change. No dangerous executable dataset, cloud inference, TLS interception or broad SMS/storage permission was added.

Model master/tools/corpus/captures remain under `/Volumes/ORBIT/Nivoryn/`. The 91 KB bundled classifier is an app resource, separate from large Llama development assets. On Android, installed resources/history use app-private no-backup storage.

## Remaining target acceptance

Official Meta source download succeeded after owner authentication. A published conversion linked directly by the official ExecuTorch README was pinned, verified and used for actual Android generation; provenance and exact hashes are in MODEL_SETUP.md. It is not claimed as a local export. Physical phone acceptance/performance, Linux hardware validation, broad OCR/adversarial evaluation and genuine feed provisioning remain pending.
