Project license

Nivoryn source is MIT-licensed. Kotlin and Jetpack Compose power the native app. The promotional website uses semantic HTML, CSS and JavaScript, with no runtime UI framework.

Assets and fonts

The graphite phone, envelope, URL strip and document specimen were authored for this direction in Blender. They are original product illustrations, not footage of a real detection engine. The Superlist recording was studied as a design reference; its media is not distributed in the website.

Manrope (500–650) and DM Sans (400–600, optical size 14) are self-hosted, limited-axis font builds from the Google Fonts repository, under the SIL Open Font License 1.1. Manrope license · DM Sans license. The app retains Noto Sans Devanagari as its Hindi fallback.

Reviewable preview

Version 0.1.0 targets Android 8.0 or newer. Source-build instructions describe the development toolchain. No verification badge, customer endorsement or detection accuracy is implied.
