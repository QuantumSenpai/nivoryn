Privacy

This product-led frontend preview does not run a web scanning service. No submitted content is accepted by this website.

The website

Fonts and product images are served locally. There are no analytics scripts, advertising cookies or third-party embeds. The website and APK downloads are served by Vercel, which receives ordinary connection/request metadata. Selecting a repository link contacts GitHub. No message or file content is submitted to this website.

The Android preview

Draft text and selected file references are kept in the application session and Android saved-instance state. They are not saved to the history database. Selected documents are opened through Android’s document picker; access is limited to selected files. The app may retain that file’s read permission to keep its preview available.

Example cases and preferences are saved in app-private SharedPreferences. You can delete cases from Settings. Android backup is disabled in this manifest. The preview requests no Internet permission and uploads no content. Local rules inspect confirmed text and URL structure. Bundled Latin/Devanagari OCR and QR decoding run on device; there is no remote analysis or model-download service. Explicitly saved text checks use AES-GCM encryption with an Android Keystore key, a 50-check limit and 30-day expiry on history reads. Delete saved checks in History or clear saved data in Settings. Original attachments are not saved to check history. PDF extraction uses a temporary app-cache copy removed on normal completion; a process crash can leave it until cache is cleared.

What still needs confirmation

Llama resources are imported into app-private storage and inference runs locally without a cloud fallback. Saved assessment snapshots retain their explanation mode and evidence; deliberate exports are plaintext copies controlled by the selected provider. Before adding connected downloads, issuer verification, crash reporting or any telemetry, document each endpoint, user choice, retention period and effect of deleting history. This page is an implementation description, not a compliance certification.
