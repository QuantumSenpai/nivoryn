Accessibility

This slice is designed around readable content, ordinary scrolling and platform controls. It is not a claim of completed WCAG certification.

Website support

Semantic headings, a skip link, visible keyboard focus, large controls and underlined example tabs are included. Use Left/Right arrows or Home/End while a tab is focused. Each example is also available as static content when JavaScript is disabled. Reduced motion removes the scroll choreography and keeps the result readable. Browser data-saving mode also avoids the animated path.

Android support

Text uses scalable sp units. Compose controls expose labels and state to accessibility services. Primary actions have at least 48dp targets. The app follows the platform animator setting and offers reduced motion. Hindi retains a bundled Devanagari fallback. Permission requests belong at the file import action rather than application launch.

Testing and remaining work

Automated keyboard, contrast and screen-size checks, host-rendered Compose checks and measurements are recorded with the source in docs/frontend/product-led/VALIDATION.md. Hardware TalkBack and mid-range Android browser performance require a connected device; automated checks do not replace them.
